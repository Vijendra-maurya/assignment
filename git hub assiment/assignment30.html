Flexbox Used (Viva Note - Module 7):

  • display:flex; - Card ko flex container banaya
  • flex-direction: row / column - Profile horizontal, Product vertical
  • flex: 1 / flex: 0 0 120px - Bacha hua space lena aur fixed size dena
  • justify-content: space-between - Title aur Price ko alag-alag kone me
  • align-items: center - Vertically center karna
  • gap: 20px - Items ke beech gap
  • flex-wrap: wrap - Mobile pe cards neeche aa jaye
  • margin-top: auto - Flex me footer ko hamesha bottom pe push karna
