    <h1>Terminal Navigation Practice Sheet</h1>

    <h2>Part 1: Basic Commands</h2>

    <ol>
        <li>Show the current directory: <code>pwd</code></li>
        <li>List files and folders: <code>ls</code></li>
        <li>Show hidden files: <code>ls -a</code></li>
        <li>Enter a folder: <code>cd Documents</code></li>
        <li>Move one directory up: <code>cd ..</code></li>
        <li>Go to the home directory: <code>cd ~</code></li>
        <li>Create a folder: <code>mkdir practice</code></li>
        <li>Enter the folder: <code>cd practice</code></li>
        <li>Create a file: <code>touch notes.txt</code></li>
        <li>Check the current directory: <code>pwd</code></li>
    </ol>

    <h2>Part 2: Practice Questions</h2>

    <ol>
        <li>Which command displays the current directory?</li>
        <li>Which command moves one directory up?</li>
        <li>Which command creates a new folder?</li>
        <li>Which command lists hidden files?</li>
        <li>Which command returns you to your home directory?</li>
    </ol>

    <h2>Part 3: Mini Challenge</h2>

    <p>Run the following commands in your terminal in order:</p>

    <pre><code>pwd
mkdir terminal_lab
cd terminal_lab
touch practice.md
ls
cd ..</code></pre>

    <h2>Expected Result</h2>

    <p>
        You will create a folder named terminal_lab, enter it,
        create a Markdown file named practice.md, list the folder
        contents, and return to the parent directory.
    </p>
