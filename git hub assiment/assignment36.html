Grid Viva Note:

.gallery{
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(250px, 1fr));
  gap: 16px;
}
  • repeat(auto-fit, minmax(250px, 1fr)) = Jitni jagah hogi utne columns, har column kam se kam 250px, bachi jagah barabar bant do. Isse responsive bina media query ke.
  • gap = Flex gap jaisa hi, par Grid me row+column dono ke liye.
  • grid-column: span 2 = Ek photo ko 2 column ka size dena (featured layout).
  • Flexbox 1D (row ya column), Grid 2D (row + column dono control).
