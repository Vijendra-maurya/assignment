Viva Note - Why it reflows automatically? 
.product-grid{
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(260px, 1fr));
  gap: 20px;
}
1. auto-fit: Bachi hui jagah ko dekh ke khud decide karta hai kitne columns banane hain. Screen badi = 4 columns, chhoti = 1 column.
2. minmax(260px, 1fr): Har card kam se kam 260px ka hoga, uske baad bachi jagah 1fr (1 fraction) se barabar bat jayegi.
3. No Media Query: Is formula se hi mobile/tablet/desktop auto handle ho jata hai. Flexbox me flex-wrap lagana padta tha, Grid me auto-fit hi kaafi hai.
Difference: auto-fill khali columns bhi bana deta hai, auto-fit khali columns ko collapse karke cards ko stretch kar deta hai — isliye product grid ke liye auto-fit best hai.
