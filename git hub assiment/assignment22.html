This box is styled using .highlight CLASS selector.

4 Selector Types Used:

  • 1. ELEMENT: body, h1, p { } - Tag se direct
  • 2. CLASS: .card, .highlight { } - Dot (.) se
  • 3. ID: #main-header { } - Hash (#) se, unique element
  • 4. ATTRIBUTE: input[type="email"] { } - Square bracket [] se
  • 5. PSEUDO-CLASS: a:hover { } - Colon (:) se - Extra
  • 6. DESCENDANT: .card ul li { } - Space se - Extra
