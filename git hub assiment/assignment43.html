REFERENCE: GRID + FLEXBOX APPROPRIATELY

When to use Flexbox vs Grid

Flexbox = 1D (row OR column) — Navbar, Hero, Buttons, Card footer. Grid = 2D (row AND column) — Features, Products, Page layout, Gallery.

Flexbox: Hero Layout Grid: Product Layout
display:flex justify-content:space-between display:grid repeat(auto-fit, minmax)
