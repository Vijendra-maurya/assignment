Viva Note - Named Areas kaise kaam karta hai?

.dashboard{
  display: grid;
  grid-template-areas:
    "header header header"
    "sidebar main main"
    "sidebar stats stats"
    "footer footer footer";
  grid-template-columns: 260px 1fr 1fr;
  grid-template-rows: 64px 1fr auto 52px;
}
.header{ grid-area: header; }
.sidebar{ grid-area: sidebar; }
.main{ grid-area: main; }
.stats{ grid-area: stats; }
.footer{ grid-area: footer; }
Benefit: Naam se layout samajh me aata hai. Responsive me sirf grid-template-areas ko badal do — poora layout mobile pe stack ho jayega, bina HTML badle.

Flexbox vs Grid Final: Flexbox 1D (menu, navbar, card ke andar). Grid 2D (poora page layout — header sidebar main footer).
