flex-wrap Viva Note:

.product-container{
  display: flex;
  flex-wrap: wrap; /* Isse cards next line pe chale jate hain */
  gap: 20px;
}
.product-card{
  flex: 1 1 260px; /* Grow, Shrink, Base 260px */
}

• flex-wrap: nowrap (default) hota to saare cards ek hi line me sikud jate.
• flex-wrap: wrap se screen chhoti hote hi cards apne aap neeche aa jate hain - responsive without media query.
• flex: 1 1 260px ka matlab: Card kam se kam 260px ka hoga, jagah milegi to badega, zarurat padegi to sikudega.
